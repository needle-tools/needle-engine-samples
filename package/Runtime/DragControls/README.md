# Drag Controls

Move, rotate, slide and snap objects with mouse, touch and XR controllers. Add `DragControls` to an object and choose a drag mode — objects can follow the pointer across surfaces, swing on a hinge, slide along a rail, rotate in place or stretch, and snap to floors, walls and grids. The same setup works on desktop, mobile and in VR/AR.

This sample is a furnished room. Furniture can be dragged around, the door swings on a hinge joint, and carpets can be dragged from the tray onto the floor.

- Drag modes for moving, rotating, sliding, hinging and stretching
- Snap to surfaces, grids and angles
- Hinge joints and colliders that respond to dragging
- Drop targets with `DragTarget`
